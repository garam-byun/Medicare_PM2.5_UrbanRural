This repository contains the code for the paper:
"Urban-Rural Disparities in PM2.5 Mortality Effects: The Roles of Chemical Composition and Population Characteristics"

## Files
- `Rcode_datasetting.R`: analytic dataset construction
- `Rcode_main_analysis.R`: main analysis

## Requirements
- R 4.3.0
- Required R packages installed

## Notes
The original Medicare data are not publicly available. Users must have authorized access to the underlying data and update file paths before running the scripts.
